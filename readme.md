# AfriSon Academy

Plateforme panafricaine d'apprentissage des instruments de musique (traditionnels africains et modernes) et de formation à l'ingénierie du son. Trois espaces (élève, enseignant, promoteur), volet événementiel et programme de parrainage.

Marché pilote : Cameroun. Interface bilingue français/anglais.

## Documentation

- [`CLAUDE.md`](./CLAUDE.md) — mémoire de travail : statut, stack, architecture, règles métier, conventions.
- [`docs/cahier-des-charges.md`](./docs/cahier-des-charges.md) — cahier des charges fonctionnel et technique complet.

## Stack

Next.js (TypeScript, App Router) pour le web et le backend, React Native pour le mobile, Neon (PostgreSQL) avec migrations versionnées, Clerk pour l'authentification, Cloudflare Stream pour la vidéo, Agora pour le live, Flutterwave (MTN Mobile Money, Orange Money) pour les paiements.
